# 残响之馆 RESIDUE

俯视角生存恐怖游戏。纯 JavaScript + Canvas，单文件，打开浏览器就能玩。

---

## ▶ 开始游戏

下载 **[`残响之馆.html`](残响之馆.html)**，双击用 **Chrome** 或 **Edge** 打开。

一个文件，不用安装、不用联网、不用装任何运行环境。

> ⚠️ 请先把文件下载到本地再打开。在网盘或论坛的「在线预览」里直接点开是存不了档的。

## 故事

九月的雨夜，S.T.R.T. 探员林岚奉命调查洛克伍德宅邸的失联事件。

线人说，宅邸「地下」有一处未申报的研究设施，代号**拉撒路**。

她走进正门的时候，还不知道这栋房子里已经没有活人了。

## 内容

- **三张地图**，从头玩到通关约 **60–90 分钟**
  - 洛克伍德宅邸 —— 家徽、半身像、保险柜，还有一个杀不死的追猎者
  - 拉撒路地下研究所 —— 断电的走廊、收容区、冷冻库
  - 赫里昂制药厂 —— 雨夜转黎明，焚化炉，最后一班货运列车
- **十一种怪物**，各有自己的行为和叫声：靠听觉找人的丧尸、装死的爬行者、一碰就炸的膨胀者、会绕路包抄的猎手……
- **两场 Boss 战**，以及一个从第一张地图追到最后的处刑者
- **谜题与探索**：家谱、日记、登记簿、值班表——线索都写在你捡到的文件里
- **资源管理**：子弹永远不够。这个游戏鼓励你绕开敌人，而不是打光它们
- **打字机存档**、3 个存档槽、通关评级结算

## 操作

| 按键 | 动作 |
|---|---|
| `W` `A` `S` `D` | 移动 |
| `左 Shift` | 奔跑 |
| `右键` / `空格` | 瞄准 |
| `左键` | 射击（瞄准时） |
| `R` | 装填 |
| `E` | 调查 / 开门 / 拾取 |
| `F` | 小刀 |
| `G` / `X` | 投掷 / 切换投掷物 |
| `Q` | 快速治疗 |
| `Tab` | 物品栏（物品 / 文件两页，`F` 切换） |
| `M` | 地图 |
| `Esc` | 暂停与设置 |

**建议戴耳机。** 声音里有大量信息——怪物的方位、猎手飞扑前的嘶气、触手钻出地面前脚下的闷响。听见了就能躲开。

## 关于存档

存档保存在浏览器本地，同一个浏览器下次打开还在。游戏里在安全屋的打字机上存档，共 3 个槽位。

- 推荐 **Chrome / Edge**。
- Safari 与无痕模式会禁止本地存储，存不了档（游戏会明确提示）。
- 浏览器的「清除浏览数据」会连同存档一起删除。

## 源码

游戏源码在 `src/`，按功能拆成 65 个文件，都是普通 `<script>`，不需要打包工具。

```bash
npm run build:html   # 生成单文件版 残响之馆.html
npm test             # 自动测试 + 地图体检 + 资源经济核算 + 数值契约
```

仓库零依赖，装了 Node 就能跑。
